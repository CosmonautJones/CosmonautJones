I'm a software engineer in Ypsilanti, Michigan. I spent eight years building and modernizing enterprise software for manufacturing companies, working across COBOL, VB.NET, C#/.NET, and SQL.

That work taught me to understand the existing system before changing it, investigate production problems carefully, and make life easier for the next developer, tester, or support person. These days I also build web products, small desktop tools, and practical AI workflows.

## How I work

- Start with a useful outcome and a small piece I can finish.
- Test failure paths as well as the happy path, and document the tradeoffs.
- Use AI to help build and investigate, with checks and human review before calling the work done.

My recent web work uses TypeScript, React, Next.js, and PostgreSQL. My enterprise background includes legacy modernization, production support, and tools that help developers and QA understand existing business logic.
